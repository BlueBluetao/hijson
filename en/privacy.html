Privacy policy

Last updated: 29 May 2025

1. Overview

HiJSON (hijson.online) is a free online JSON tool. This page describes what may be collected when you use the site.

2. JSON data

Core features run locally. Parse, format, tree view, and JSONPath do not upload your JSON to a HiJSON server.

  • JSONBin share: if you set a key and share, data goes to JSONBin.io under their policy.
  • AI chat: if you configure an LLM API, the conversation and JSON context go to that provider. HiJSON does not store it.

3. LocalStorage

Language, panel sizes, path memory, and optional API keys stay on your device. Clear site data in the browser to remove them.

4. Cookies and analytics

  • Google Analytics (G-2NFFPZ49CE): traffic and usage. See Google’s policy.
  • Google AdSense: ads may use cookies. Manage ads at Google ad settings or aboutads.info.

5. Hosting logs

The site is on GitHub Pages. GitHub and the CDN may keep standard request logs. HiJSON does not collect those logs itself.

6. Children

The site is not directed at children under 13. We do not knowingly collect their personal information.

7. Changes

Updates appear on this page with a new date. Continued use means you accept the revised policy.
