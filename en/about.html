About HiJSON

Who we are

HiJSON is a free in-browser JSON tool at hijson.online. No account. Core parse, format, tree, and JSONPath run on your machine.

Why it exists

Debugging APIs and reading logs is constant. Some tools split features across tabs; some upload the payload. HiJSON keeps the default path local and still has a tree, JSONPath, field compare, and optional AI if you bring your own key.

Features

  • Format and minify
  • Tree view and outline
  • JSONPath and multi-field compare
  • File import (.json / .txt / .jsonl)
  • Optional AI (your OpenAI-compatible API)
  • Optional share via JSONBin.io
