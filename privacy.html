隐私政策

最后更新：2025 年 5 月 29 日

1. 概述

HiJSON（hijson.online）是一款免费的在线 JSON 解析与格式化工具。我们重视您的隐私。本政策说明在您使用本网站时，我们可能收集哪些信息以及如何使用这些信息。

2. JSON 数据处理

核心功能在本地执行。您在 HiJSON 中粘贴或导入的 JSON 数据，其解析、格式化、树形展示、JSONPath 查询等操作均在您的浏览器本地完成，不会上传至 HiJSON 服务器。

以下情况可能涉及第三方服务：

  • JSONBin 分享：若您主动配置 JSONBin.io API Key 并使用分享功能，JSON 数据将上传至 JSONBin.io，受其隐私政策约束。
  • AI 对话：若您配置 LLM API，对话内容及 JSON 上下文将发送至您指定的 API 提供商，HiJSON 不存储这些内容。

3. 本地存储（LocalStorage）

HiJSON 使用浏览器 LocalStorage 保存以下偏好设置，数据仅存储在您的设备上：

  • 界面语言偏好
  • 面板宽度与折叠状态
  • 路径记忆（若开启记忆模式）
  • JSONBin API Key（若您主动配置）
  • AI 配置信息（若您主动配置）

您可随时通过浏览器设置清除 LocalStorage 数据。

4. Cookie 与分析服务

本网站使用以下第三方服务，这些服务可能设置 Cookie 或类似技术：

  • Google Analytics（G-2NFFPZ49CE）：用于统计网站访问量、页面浏览和用户行为，帮助改进产品。Google 可能收集 IP 地址、浏览器类型、访问时间等信息。详见 Google 隐私政策。
  • Google AdSense：本网站可能展示 Google 提供的广告。Google 及其合作伙伴可能使用 Cookie 根据您的访问记录展示个性化广告。您可在 Google 广告设置 中管理偏好，或访问 aboutads.info 选择退出个性化广告。

5. 日志与服务器数据

HiJSON 托管于 GitHub Pages。GitHub 及 CDN 提供商可能记录标准的 Web 服务器日志（如 IP 地址、User-Agent、请求 URL、时间戳），用于安全与运维目的。HiJSON 不主动收集或存储这些日志。

6. 儿童隐私

本网站不面向 13 岁以下儿童，我们不会故意收集儿童的个人信息。

7. 政策变更

我们可能不时更新本隐私政策。变更将在本页面发布并更新「最后更新」日期。继续使用本网站即表示您接受更新后的政策。
